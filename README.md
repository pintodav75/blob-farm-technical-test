# Blob farm — take-home technical test

Full-stack TypeScript take-home test (Express API + React front end on a shared
TypeScript setup). **Completed November 2022 — it led to an internship.**

**Stack:** TypeScript, Express, React, Less · **Context:** take-home test

## What I added

Starting from the company's starter template (its documentation is kept in
[`TEMPLATE.md`](TEMPLATE.md)), I implemented:

- the Express **back-end** for the blob resources — see commit `basic backend ok`
- the React **front-end** consuming it — commits `front ok`, `projet fini`

## Run

```bash
yarn        # or npm install
yarn dev    # back-end (nodemon) + front-end (webpack dev server), concurrently
```
